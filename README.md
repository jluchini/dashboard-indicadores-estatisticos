# Dashboard de Indicadores Estatísticos

Dashboard desenvolvido para a disciplina de **Estatística**, do curso de **Sistemas de Informação da UNIFEBE**.

O projeto apresenta uma análise comparativa de indicadores de **Brusque, Santa Catarina e Brasil**, considerando os anos de **2017, 2019, 2021 e 2023**.

## Indicadores analisados

- Água canalizada
- Energia
- Coleta de lixo
- Expectativa de vida
- Taxa de analfabetismo
- Taxa de natalidade
- População
- Matrículas na educação

## Dashboard

Os dados podem ser visualizados de forma interativa, permitindo selecionar o local, o ano e o indicador desejado.

🔗 **Acessar o Dashboard:** https://jluchini.github.io/dashboard-indicadores-estatisticos/
